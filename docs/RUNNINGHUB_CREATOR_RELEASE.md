# RunningHub 创作者发布说明

## 作品定位

作品名：`一键漫剧 H3 导演台｜9图3视频6音轨｜5-15秒`

本工作流不是对社区作品换名发布。执行链以 ComfyUI 官方 MiniMax H3 Ref2VA
工作流为上游，从画布结构、输入语义、时长控制、速度档位、提示词框架到教学说明
重新设计。发布时应准确表述为“原创工作流编排与应用设计”，不得宣称 MiniMax H3
模型、ComfyUI 节点或 LightX2V LoRA 为原创。

## 原创功能

- 把 9 张参考图拆成角色、场景、物品/画风三类教学语义。
- 同时提供 3 个动作/运镜视频、3 路视频原声和 3 路独立声音参考。
- 使用 5-15 秒真实时长控件，按 24fps 换算 H3 合法帧数。
- 默认 4 步极速档，同时保留 8 步均衡档。
- 提供官方 Ref2VA 六段式导演提示词骨架，即梦自然语言直接写入 `detailed_description`。
- 只生成一个带原生同步音频的 MP4，适合软件 API 和学员审片。
- 节点按学员操作顺序排布，模型与推理核心单独封装。

## 上游署名

- MiniMax H3 模型与算法：MiniMax-AI。
- H3 节点与 Ref2VA 示例：Comfy-Org / ComfyUI。
- 加速 LoRA：LightX2V 对应模型发布者。
- 视频载入节点：ComfyUI Video Helper Suite。

发布页应保留上游链接和模型许可信息。项目根目录的
`MINIMAX_H3_LICENSE.txt` 与 `NOTICE.md` 不能删除。

## 发布前清单

1. 使用自己制作或有权使用的角色、场景、物品素材替换所有示例占位文件。
2. 分别测试 9:16 和 16:9；测试 5 秒、10 秒和 15 秒。
3. 测试单图、多图、视频原声和独立音频四种输入组合。
4. 记录 Standard 与 Plus 的真实耗时、RH币消耗和失败率。
5. 制作自己的封面、演示视频、使用说明和提示词案例。
6. 先以私有链接邀请少量学员试用，修复问题后再公开发布。
7. 发布文案注明模型/节点上游，原创范围只写工作流编排与应用设计。

## 学员使用和收益

建议发布为 AI 应用，让学员只看到素材上传、提示词、时长、比例和速度档位，隐藏
模型与采样节点。公开工作流或 AI 应用的有效运行（包括相应 API 调用）、收藏量与
原创程度可参与 RunningHub 创作者激励。不要把个人 API Key 直接发给学员。
